## 4. Panduan Klien Mengubah Isi Website
Klien dapat memperbarui informasi di website sewaktu-waktu dengan 2 pilihan cara:

### Cara A: Melalui Bantuan Pengembang (Praktis)
1. Kirim materi baru (teks atau foto pengganti) via pesan WhatsApp atau email ke kontak dukungan pengembang.
2. Pengembang akan memperbarui data dan melakukan publikasi (deploy) ulang ke server.

### Cara B: Mandiri via Editor Web GitHub (Tanpa Perlu Instalasi)
1. Masuk ke akun GitHub Anda dan buka tautan repositori website ini.
2. Buka folder `src/data/`, lalu pilih file yang ingin diubah (contoh: `profile.js` untuk profil, `projects.js` untuk portofolio karya).
3. Klik ikon pensil (**Edit this file**) di pojok kanan atas file.
4. Ubah teks di dalam tanda kutip sesuai data terbaru.
5. Klik tombol hijau **Commit changes...**.
6. Server hosting akan secara otomatis mendeteksi perubahan dan memperbarui website Anda dalam waktu kurang dari 1 menit!

## 5. Lembar Pemeriksaan Tanda Terima (Checklist Klien)
Sebelum menyetujui serah terima ini, mohon periksa poin-poin berikut bersama pengembang:

- [ ] **Tampilan HP (Mobile):** Tampilan rapi, teks mudah dibaca, dan tidak ada elemen bergeser ke samping.
- [ ] **Tampilan Laptop/Desktop:** Tata letak seimbang dan responsif di resolusi layar lebar.
- [ ] **Tautan dan Tombol:** Tombol WhatsApp, email, dan tautan sosial media mengarah ke tujuan yang benar.
- [ ] **Ejaan dan Penulisan Teks:** Nama, gelar, profesi, dan deskripsi sudah bebas dari salah ketik (typo).
- [ ] **Foto dan Thumbnail Karya:** Gambar profil dan karya tertampil jelas dan tajam.
